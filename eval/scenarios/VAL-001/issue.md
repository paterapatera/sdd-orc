# 自分のログインの記録を、設定の画面で見られるようにしたい（GitHub issue #5）

## 背景

利用者から「知らないうちに誰かにログインされていないか確かめたい」という問い合わせが来ている。今はアプリの中に、自分がいつ、どこからログインしたかを確かめる手段が無い。

## やりたいこと

- ログインした利用者が、自分のログインの記録を設定の画面（`/settings/login-history`）で見られるようにする
- これから行われるログインを記録する（この issue より前のログインは記録が無いので、表示しなくてよい）

## この issue でやらないこと

- 不審なログインの通知（メールなど）
- ほかの端末のログインを終わらせる操作
- 管理者が、ほかの利用者の記録を見る画面
