# Answers

人間役の答え。質問ごとに、意味が同じ選択肢を選ぶ。どの行も答えていない質問は `unanswered` と記録し、`default` で選ぶ。

- 範囲: 記録・閲覧・編集・削除をすべて含める。一覧から1件を選んで操作する
- 本の指定: 本のタイトルを手入力する。蔵書・読了とはつながない。将来蔵書機能ができてもつなげなくてよい
- 感想の中身: 自由記述、記録日、評価（星1〜5）。タイトルと自由記述は必須、評価は任意、記録日は既定で今日で変更できる
- 誰が使うか: ログインした本人だけ。ログインしていない人には何も見せずログイン画面へ
- 他人の感想を開いたとき: 「見つからない」と表示し、中身は見せない
- 削除: 削除前に確認する。削除したら戻せなくてよい
- 入力の誤り: 何も保存せず、入力した内容を残したままフォームに戻り、どこが誤りか示す
- 二重送信・同時編集: 二重に押しても1件だけ記録される。同時編集は後から保存したほうで上書きでよい
- 件数・速度: 条件なし
- 何もないとき: 「まだ感想がありません」と記録への導線を出す
- 範囲の拡張や分割: 1つの spec に含める
- default: 迷ったら、利用者のデータが失われず他人に見えない方を選ぶ
