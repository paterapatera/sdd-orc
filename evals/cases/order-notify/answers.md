# Answers

人間役の答え。質問ごとに、意味が同じ選択肢を選ぶ。どの行も答えていない質問は `unanswered` と記録し、`default` で選ぶ。

- 通知先: 店舗ごとに1つの Slack チャンネル。店舗の管理者が管理画面で設定する
- 通知内容: 注文番号、合計金額、受取時刻。顧客の氏名・電話番号は載せない
- Slack が止まっているとき: 注文の確定は止めない。通知は後で送り直し、1時間届かなければ管理画面に未送信として表示する
- 二重通知: 同じ注文を2回通知しない
- 通知先が未設定: 通知せず、管理画面に未設定と表示する
- 件数・速度: 確定から1分以内に届けばよい
- 範囲の拡張や分割: 通知先の設定画面は別 spec に分ける
- default: 迷ったら、注文の確定を止めない方、個人情報を出さない方を選ぶ
