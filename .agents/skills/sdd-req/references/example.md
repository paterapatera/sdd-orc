# 注文履歴のCSVダウンロード

## 顧客への確認事項

- [x] Q-01: 指定できる期間を最大12ヶ月とした（関連: order-export.period-limit）
- [ ] Q-02: キャンセルされた注文の金額を0円として出力してよいか（関連: order-export.csv-columns）
- [ ] Q-03: CSV出力は経理ロールを持つ人だけが使えるようにした（関連: auth.accounting-role）

## ユーザーストーリー

- 利用者: 経理担当者
- やりたいこと: 期間を指定して注文履歴をCSVで取得したい
- 目的: 会計システムへ手作業なしで取り込むため
- 出典: #42

## 目的・成功の基準

- 月次の取り込み作業を、現在の約3時間から15分以内にする。

## スコープ

### 対象

- 期間を指定して、注文履歴をCSVで出力する。

### 対象外

- Excel形式での出力。
- 定期的な自動送信。

## 用語

- 注文履歴: 状態が「完了」または「キャンセル」の注文。（新規）
- 経理ロール: 会計に関する操作を許可された利用者の権限。

## 要件

### order-export.csv-download CSVのダウンロード

- 種別: 機能
- 要件: 経理担当者が期間を指定してダウンロードを実行したとき、システムは該当期間の注文履歴をCSVで提供する。
- 根拠: issue
- 受け入れ条件:
  - order-export.csv-download.ac1 正常に出力できる
    - 前提: 2026年8月の注文履歴が120件ある。
    - 操作: 期間を2026/8/1〜2026/8/31にしてダウンロードする。
    - 結果: 見出し行と120行のデータを含むCSVが得られる。
  - order-export.csv-download.ac2 対象が0件
    - 前提: 2026年7月の注文履歴が0件である。
    - 操作: 期間を2026/7/1〜2026/7/31にしてダウンロードする。
    - 結果: 見出し行だけのCSVが得られる。

### order-export.csv-columns CSVの項目

- 種別: 機能
- 要件: システムは、CSVに注文番号、注文日時、税込金額、注文の状態を、この順で出力する。
- 根拠: issue, Q-02
- 受け入れ条件:
  - order-export.csv-columns.ac1 キャンセルされた注文
    - 前提: 税込12,800円の注文がキャンセルされている。
    - 操作: その注文を含む期間でダウンロードする。
    - 結果: その注文の税込金額は0、状態は「キャンセル」と出力される。

### order-export.period-limit 期間の上限

- 種別: 機能
- 要件: 指定期間が12ヶ月を超える場合、システムはエラーを表示し、出力しない。
- 根拠: Q-01
- 受け入れ条件:
  - order-export.period-limit.ac1 期間超過
    - 前提: 経理担当者としてログインしている。
    - 操作: 期間を13ヶ月にしてダウンロードする。
    - 結果: エラーが表示され、ファイルは出力されない。

### auth.accounting-role 経理ロールの権限

- 種別: 非機能
- 要件: システムは、経理ロールを持つ利用者にのみ、請求書の閲覧と注文履歴のCSV出力を許可する。
- 根拠: 既存仕様, Q-03
- 受け入れ条件:
  - auth.accounting-role.ac1 権限がない利用者
    - 前提: 経理ロールを持たない利用者としてログインしている。
    - 操作: 注文履歴画面を開く。
    - 結果: CSVダウンロードの操作が表示されない。

## 制約・前提

- 注文件数は最大で月5万件を想定する。
